# 커버 연습실 (시안)

연습용 반주 플레이어, 채보, 편곡 가이드, 시창·청음을 한 화면에 묶은 정적 웹 앱입니다. 서버 없이 `index.html`과 `sing.js`만으로 동작합니다.

## 기능

- **곡**: One Dream 후렴 4마디(실제 렌더 음원 포함 데모)와 원작 연습곡 1(미디엄 팝 발라드, 16마디, 브라우저 합성). 올린 곡은 「내 곡」으로 추가됩니다.

- **연습**: 파트별 볼륨·끄기(M)·솔로(S), 속도 25~110%(음정 유지), 키 변경(브라우저 합성), 구간 반복, 단계 연습(시작·목표·단계·반복 횟수 설정, 속도 옆 ↑ 표시), 카운트인, 메트로놈, 반주 스타일(발라드·팝·록·어쿠스틱, 내 곡).
- **구간 반복**: 코드 띠에서 끌어(터치는 길게 눌러 끌어) 정하고, 띠 양 끝 손잡이로 길이를 고칩니다. 빈 곳을 누르거나 「반복 해제」로 풉니다. 채보 그림에서 끌어도 됩니다.
- **채보**: 피아노롤에 재생 위치를 따라가며 음을 보여 주고, 마디를 누르면 음·드럼 격자를 풀어 보여 줍니다.
- **가이드**: 구간 카드(누르면 그 구간 반복), 마디별 코드·로마숫자 기능, 파트 역할 카드, 바꿔 볼 수 있는 힌트. 내 곡은 코드 칸을 눌러 고칠 수 있습니다.
- **시창·청음**: 키·음역 안의 짧은 멜로디를 듣고 마이크로 부르면 음마다 판정합니다. 「지연 맞추기」로 마이크 왕복 지연을 재서 판정에 반영합니다. 청음은 음정·3화음·7화음 성질(maj7·7·m7, 난이도 2에서 하프 디미니시·dim7)·음계 도수(I–IV–V–I 뒤 한 음의 도수) 퀴즈이고 정답률이 기록됩니다.
- **음정 부르기**: 기준음을 듣고 같은 음 내기, 또는 음정 이름·방향대로 부르기. 처음 발성 0.15초 뒤 0.6초 창의 cent 중앙값이 ±50 cent 안이면 「맞음」(옥타브 차이는 별도, 흔들림·무음은 기록 안 함). 결과는 적응형 통계에 `pm:<음정>:<asc|desc>`(같은 음은 `pm:동음:same`)로 쌓여 약점 목록·설명에 나옵니다(오늘의 연습에는 「음정 부르기 포함(마이크)」 설정을 켰을 때 끝에 3–4번 덧붙고, 마이크가 없으면 그 블록만 건너뜀. 약점만 다시에도 pm 약점이 나옴). 신호 기반 판정입니다.
- **올리기**: MP3·WAV를 올리면 BPM·첫 박 추정, 채보(Basic Pitch), 마디별 코드·키(메이저·마이너 기본, 근거가 있을 때만 7·maj7·m7·sus·dim·슬래시 베이스, 반마디 분할), 베이스·건반·드럼 반주 초안을 만듭니다. 기타는 원곡 구성을 알 수 없어 만들지 않습니다. BPM·첫 박은 고쳐서 다시 맞출 수 있습니다.
- **사용 설명서**: `help.html`(탭별 사용법, 단축키, 개인정보, 분석의 한계, FAQ). 상단 `?` 창과 푸터에서 열립니다.
- **내보내기**: 지금 설정(키·템포·켠 파트·볼륨)대로 MIDI와 WAV(브라우저 합성 반주)를 받습니다. 좁은 화면에서는 「더보기」 안에 있습니다.
- **저장**: 분석 결과(채보 음·BPM·첫 박·고친 코드·스타일)만 이 브라우저(IndexedDB)에 저장합니다. 원본 파일은 저장하지 않습니다. 테마, 컨트롤 접힘, 단계 연습 설정, 마이크 지연, 청음 정답률은 localStorage에 둡니다. 저장이 막힌 환경에서도 연습은 그대로 됩니다.
- **화면**: 하단 컨트롤은 접어서 재생·위치만 남길 수 있고(상태 유지), 어두운·밝은 테마를 지원합니다.

- **음색**: 브라우저 합성 반주는 「음색: 샘플 / 합성」을 고를 수 있습니다(저장됨). 샘플은 처음 쓸 때만 불러오고(약 3 MB), 준비되기 전에는 합성음으로 재생합니다. WAV 내보내기도 같은 음색을 씁니다. 「저음 −4 dB」는 베이스·건반의 저음을 낮추는 기본 설정이며 끌 수 있습니다. 샘플 출처·라이선스는 [samples/CREDITS.md](samples/CREDITS.md).

## 단축키

`?`로 전체 목록을 엽니다.

| 키 | 동작 |
|---|---|
| Space | 재생 / 정지 |
| Home | 처음으로 |
| ← → | 한 마디 이동 |
| [ ] | 속도 -5% / +5% |
| L | 구간 반복 켜기/끄기 |
| M | 메트로놈 켜기/끄기 |
| 1-4 | 베이스·건반·드럼·기타 끄기/켜기 (Shift = 솔로) |

입력칸·선택칸·슬라이더에 포커스가 있으면 단축키는 꺼집니다.

## 개인정보

- 올린 음악 파일은 서버로 전송되지 않습니다. 디코드, 박자·채보·코드 분석, 반주 생성이 모두 이 브라우저 안에서 일어납니다.
- 마이크 소리는 음높이와 지연을 계산하는 데만 쓰고 저장하거나 보내지 않습니다.
- 분석 결과를 저장하는 곳은 이 브라우저뿐이며, 「지우기」로 지울 수 있습니다.

## 판정 방식

모든 수치와 판정은 신호 기반 분석입니다. 사람이 듣고 평가한 결과가 아닙니다.

- 박자·코드·키: 에너지 변화의 주기성과 마디별 음 분포로 추정합니다. 틀릴 수 있어 결과 카드에서 고칠 수 있습니다.
- 시창: 음마다 앞 15%·뒤 10%를 뺀 구간에서, 소리가 잡힌 프레임 중 ±50 cent 안에 든 비율이 60% 이상이면 「맞음」입니다.
- 마이크 지연: 스피커 클릭 4번이 마이크 기록에 나타나는 시각과 예약 시각의 차이(중앙값)를 쓰며, 이어폰을 쓰면 잴 수 없습니다.

## 구성

- `index.html`: 화면과 앱 로직 전체.
- `sw.js`, `manifest.webmanifest`: 오프라인 사용·설치(코드는 네트워크 우선, 음원·모델·아이콘·샘플은 캐시 우선. 캐시 우선 자원을 바꾸면 `sw.js`의 `V`를 올립니다).
- `help.html`: 사용 설명서(독립 페이지). `404.html`, `robots.txt`, `sitemap.xml`, `icons/og-image.png`(공유 미리보기 1200×630).
- `vocal.js`: 원곡 보컬 멜로디(추정) — 가운데 채널 하모닉 살리언스 + 채보 음 후보를 합친 비터비 추적. 업로드 때 한 번 계산해 `song.parts.vocal`(기본 꺼짐)로 둔다. 측정은 `bench_20261107/README_ko.md` 보컬 절.
- `sing.js`: 시창·청음 코어(음높이 추정, 멜로디 생성, 판정, 지연 추정, 청음 문제).
  적응형 청음(오늘의 10분 연습): 항목별 세부 통계 `pr-stats2`(옛 `pr-stats`에서 이관), 약점 계산(`weakness`), 약점 가중 출제, 틀린 문제 2–4문제 뒤 재출제, 혼동 쌍 기반 설명.
- `vendor/`: Basic Pitch 1.0.1 (Apache-2.0)와 모델. TensorFlow.js 3.21은 CDN에서 불러옵니다.
- `audio/`: 데모 음원(One Dream 후렴 17-20마디 렌더, 이 프로젝트 제작).
- `DESIGN_SPEC_ko.md`, `PLAN_ko.md`: 디자인 명세와 기획 메모.

## 실행

```
python3 -m http.server 8000
```

열고 `http://localhost:8000/` 로 접속합니다. 마이크는 `localhost` 또는 https에서만 열립니다.
