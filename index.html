곡을 올리면 베이스·드럼·건반·기타를 새로 연주한 반주를 만들어 드립니다. 파트를 끄고 켜며 연습하고, 채보를 보며 음을 확인하고, 코드 진행과 각 파트의 역할을 읽어 내 편곡의 출발점으로 쓰세요.

One Dream 후렴으로 바로 들어보기내 곡 올려서 채보하기

데모 곡은 이 프로젝트에서 실제로 만든 반주(One Dream 후렴 4마디)입니다. 내 곡을 올리면 브라우저 안에서 채보(Basic Pitch)·박자·코드 분석과 반주 초안 생성이 실제로 돌아갑니다. 파일은 서버로 가지 않습니다.

0 · 곡 올리기

파일 하나로 시작합니다

파일은 이 브라우저 밖으로 나가지 않습니다. 채보(Basic Pitch)·박자·코드 분석과 베이스·건반·드럼 반주 초안이 기기 안에서 만들어지고, 끝나면 연습실·채보·가이드가 내 곡으로 바뀝니다. 3분 곡 기준 30초~2분 걸립니다.

채보와 반주 초안이 준비됐습니다
박자 추정이 틀리면 BPM(절반·두 배도 확인)과 첫 박 위치를 고치고 다시 맞추세요. 채보 모델은 다시 돌지 않습니다.
연습실에서 열기채보 보기편곡 가이드

이 브라우저에서 지금 되는 것 / 서버가 필요한 것

지금채보 Basic Pitch 모델이 전체 믹스의 음을 받아 적습니다(보컬 포함, 악기 분리 없음).
지금박자 에너지 변화의 주기성으로 BPM과 첫 박을 추정합니다. 틀리면 결과 카드에서 고칠 수 있습니다.
지금코드·키 마디별 음 분포로 메이저·마이너 3화음과 키를 추정합니다.
지금반주 초안 코드에서 베이스·건반·드럼을 생성해 브라우저 합성으로 재생합니다. 기타는 원곡 구성을 모르는 상태라 넣지 않습니다.
서버분리(Demucs) → 파트별 정밀 채보 → 원곡 악기 구성 반영 편곡 → 실제 음원 렌더(WAV·스템·MIDI). 정식 버전에서 제공합니다.

모든 수치는 신호 분석 결과이며 청취 검증이 아닙니다. 보컬 멜로디도 채보에 섞여 들어오므로 코드 추정이 흔들리는 마디가 있습니다.
